# Multi-Source Sentiment Analysis for India

Sentiment analysis pipeline for Indian financial markets using multiple data sources.

## Project Structure

- **data_raw/**: Raw data from multiple sources
  - news/: Financial news articles
  - mdna/: Market DNA data
  - forums/: Discussion forums
  - politics/: Political news

- **data_processed/**: Processed sentiment data
  - daily_sentiment/: Daily aggregated sentiment
  - quarterly_sentiment/: Quarterly aggregated sentiment

- **src/**: Source code modules
  - data_collection/: Data collection scripts
  - preprocessing/: Text preprocessing
  - sentiment_models/: Sentiment analysis models
  - aggregation/: Sentiment aggregation
  - analysis/: Analysis and reporting

- **notebooks/**: Exploration and analysis notebooks

- **experiments/**: Model runs and experiments

- **docs/**: Documentation
